# Reporting Tool — Анализ обучения ОС ГД

Инструмент для анализа данных обучения сотрудников по образовательной системе Газпромнефть с подсчётом статистики по годам.

## Возможности

- Объединение нового файла выгрузки с накопительным итоговым файлом
- Автоматическое удаление дубликатов записей
- Классификация курсов по категориям: **BP** (бизнес-пользователи), **IT**, **ПРМ** (поддержка рабочих мест)
- Подсчёт уникальных обучающихся и человеко-курсов
- Статистика по годам (2022–2026): итоговая, накопительная, за отдельный год
- Выявление неклассифицированных курсов
- Экспорт отчёта в Excel

## Два варианта

### Консольная версия

```
python для_ос_гд_с_подсчетом_за_2026_год.py
```

- Открывает диалоги выбора файлов
- Результаты выводит в консоль
- Автоматически сохраняет отчёт в Excel

### GUI-версия (customtkinter)

```
python для_ос_гд_с_подсчетом_за_2026_год_gui.py
```

- Полноценный графический интерфейс
- Прогресс-бар с отображением текущего этапа обработки
- Интерактивное управление неклассифицированными курсами:
  - Поиск по названию
  - Назначение каждого курса в категорию (BP / IT / PRM) или в блеклист
  - Пересчёт статистики после назначений
- Сохранение пользовательских назначений в `course_assignments.json` (загружаются автоматически при следующем запуске)
- Вкладка «Назначения» — просмотр и удаление пользовательских назначений
- Экспорт отчёта в Excel через диалог сохранения

## Зависимости

```
pip install pandas openpyxl customtkinter
```

- `pandas` — обработка данных
- `openpyxl` — чтение/запись Excel
- `customtkinter` — GUI (только для GUI-версии)

## Сборка в .exe

```
build.bat
```

Использует PyInstaller для создания standalone `.exe` файла из консольной версии.

## Формат входных данных

Ожидается Excel-файл (`.xlsx`) со столбцами:

| Столбец | Описание |
|---|---|
| Название | Название курса |
| Статус | Статус прохождения |
| Дата начала | Дата начала обучения |
| Дата завершения | Дата завершения обучения |
| ФИО участника | ФИО обучающегося |
| Подразделение | Подразделение сотрудника |
| Должность | Должность сотрудника |
| Предприятие сотрудника | Предприятие |
